المشكلة:
- Vercel يحفظ CSS/JS لمدة سنة كاملة (max-age=31536000, immutable)
- حتى بعد رفع ملفات جديدة، المتصفح يستخدم النسخة القديمة
- CTRL+SHIFT+R لا يقدر يتجاوز cache في بعض الحالات

الحل:
- إضافة ?v=20260915 على كل روابط CSS/JS المحلية
- مثال: <script src="config.js?v=20260915">
- هذا يجبر المتصفح على تحميل النسخة الجديدة عند كل تغيير

🌍 الإصلاح #2: تحسين منطق اللغة (i18n.js + 13 ملف HTML)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

المشكلة:
- المستخدم يبدّل اللغة لكن بعد refresh ترجع للغة الأصلية
- السبب: المتصفح يحتفظ بالنسخة القديمة من i18n.js

الحل:
1. i18n.js: تحسين getInitialLang() بأولويات واضحة:
   - الأولوية 1: ?lang=ar في URL
   - الأولوية 2: localStorage.cc_lang
   - الأولوية 3: cookie cc_lang (احتياطي)
   - الأولوية 4: لغة المتصفح (fallback نهائي)

2. setLang(): حفظ اللغة في localStorage AND cookie
   - localStorage قد يُمسح في incognito mode
   - cookie تبقى لمدة سنة كاحتياطي

3. early lang script في كل HTML (13 ملف):
   - يُنفّذ فوراً قبل تحميل CSS/JS
   - يقرأ localStorage + cookie
   - يطبّق lang/dir على <html> مباشرة

🔔 الإصلاح #3: منع تكرار الإشعارات (notifications.js)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

المشكلة:
- نفس الإشعار يظهر عدة مرات في لوحة الإشعارات
- السبب: createNotification يحفظ بدون فحص التكرار
- loadNotifications يجلب كل الإشعارات من DB بدون deduplication

الحل:
1. createNotification:
   - فحص التكرار بناءً على (title + message + type)
   - إذا وُجد إشعار بنفس المحتوى خلال آخر 5 دقائق، لا يُضاف

2. loadNotifications:
   - إزالة الإشعارات المكررة من قاعدة البيانات
   - استخدام Set للتحقق من المحتوى الفريد

🔧 طريقة التركيب
══════════════════════════════════════════════════════════════

1. استخرج ملفات الأرشيف
2. انسخ كل الملفات إلى جذر مشروعك (استبدال القديمة)
3. ارفع المشروع لـ Vercel

══════════════════════════════════════════════════════════════
⚠️ مهم جداً بعد التركيب
══════════════════════════════════════════════════════════════

بعد رفع الملفات الجديدة، امسح الكاش القديم يدوياً:

في Chrome/Edge:
1. F12 → Application → Storage → Clear site data
2. أو: Settings → Privacy → Clear browsing data → Cached images and files

في Firefox:
1. F12 → Storage → Clear All
2. أو: Settings → Privacy → Clear History

بعد مسح الكاش:
- افتح الموقع → اللغة ستكون حسب تفضيلك المحفوظ
- بدّل اللغة → ستثبت حتى بعد CTRL+SHIFT+R
- الإشعارات لن تتكرر

✅ التحقق من النجاح
══════════════════════════════════════════════════════════════

1. تحقق من ?v= في روابط الملفات:
   - F12 → Network → تحديث الصفحة
   - يجب أن ترى: config.js?v=20260915, i18n.js?v=20260915, إلخ

2. تحقق من ثبات اللغة:
   - بدّل للعربية
   - CTRL+SHIFT+R → يجب تبقى عربي
   - افتح capsules.html → يجب تبقى عربي

3. تحقق من الإشعارات:
   - افتح لوحة الإشعارات
   - يجب ألا تكون هناك تكرارات
